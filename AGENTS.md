# Установка Zorya Code Explorer

Если пользователь просит «Установи MCP из https://github.com/zoomplus/zorya-code-explorer в текущий проект и проверь его», выполни установку и проверку для текущего проекта.

1. Определи точный корень выбранного Codex-проекта. `.git` не обязателен, если это обычный проект с распознанной Codex-конфигурацией `.codex/config.toml`. Не выбирай домашний каталог, соседний проект или checkout самого сервера.
2. Проверь наличие Node.js 20.19+ и npm. Скачай `https://raw.githubusercontent.com/zoomplus/zorya-code-explorer/installer-v1/install.mjs` во временную папку вне проекта и запусти `node <путь-к-install.mjs> --project <абсолютный-путь-к-проекту>`. GitHub CLI, GitHub-аккаунт, исходный checkout и ручные команды проверки архива не нужны.
3. Дай bootstrap-скрипту скачать закреплённый бинарный архив и checksum, проверить их, распаковать в staging вне проекта, установить production-зависимости через `npm ci --omit=dev --ignore-scripts` и запустить штатный проектный установщик. Не заменяй эти шаги сборкой из исходного кода.
4. Убедись, что MCP-запись добавлена только в `<проект>/.codex/config.toml`; global settings, `package.json` и зависимости проекта не менялись. Установщик не должен перезаписывать существующий checkout. Для повторного использования выполняй только его проверенную процедуру сравнения с чистой распаковкой; при несовпадении сохрани существующие файлы и остановись.
5. Разрешение клиенту использовать проектную конфигурацию и доверие к MCP-серверу — решения пользователя. Не включай автоматическое одобрение. После подтверждения открой новый чат.
6. Через реальный MCP-клиент проверь handshake и `tools/list` (14 инструментов), вызови `explorer_open` и сверь `snapshot.root` с точным корнем проекта. Затем вызови `explorer_source` для сущности из этого кадра. Если путь не совпадает или исходник не читается, не сообщай об успешной установке.

Без отдельного внешнего operator config доступны только операции чтения. Не включай запись, проверки или внешний поиск без явного разрешения владельца. Если владелец предоставил внешний config вне проекта, передай его bootstrap параметром `--config <абсолютный-путь>`. Внешние embeddings/reranking передают провайдеру кодовые фрагменты и запросы.

Сборка предназначена приглашённым пользователям и помечена `UNLICENSED`. Публичный bootstrap не раскрывает TypeScript-исходники и историю; не называй сам бинарный JavaScript некопируемым.
